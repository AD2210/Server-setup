# v0.0.12 — sauvegardes vérifiées et monitoring

Cette version ajoute la conservation de la dernière sauvegarde réussie, la copie
vérifiée vers un poste d'administration et la compatibilité avec Vector récent.

- `LOCAL_RETENTION_COUNT` et `REMOTE_RETENTION_COUNT` permettent de conserver un
  nombre de sauvegardes réussies par type ; `0` conserve la rétention par jours.
- `REMOTE_BACKUP_ENABLED=false` active explicitement les sauvegardes locales
  pendant la configuration rclone, sans annoncer une copie distante.
- Les transferts distants sont sérialisés pour éviter les dossiers Google Drive
  dupliqués. `rclone check` précède la rotation des anciennes copies.
- `server-backup-export` et `scripts/pull-backup.sh` exportent des jeux complets,
  vérifient les SHA256 et remplacent la copie du poste après validation.
- Vector utilise son fichier d'environnement root avec l'option d'interpolation
  requise depuis la version 0.57. Sa configuration est vérifiée sans tester les
  endpoints lorsque l'API centrale n'est pas encore configurée.
- Les tags Git Flow publient la GitHub Release après la QA et les tests.

Validation : QA statique stricte, tests de provisionnement et d'isolation API,
tests de rétention avec rclone local, sauvegardes PostgreSQL/fichiers réelles,
vérification Google Drive et copie sur poste avec contrôle SHA256.
